# edison

一个自用、原生、低功耗的 macOS 菜单栏状态监控应用。

## 当前目标

- 在菜单栏常驻一个简洁图标。
- 点击图标后，以紧凑面板展示 CPU、GPU、温度、AirPods Pro 电量、Codex 剩余用量和 Mac 开机时间。
- UI 参考 Status/Stats 类应用，保持简洁、美观，并面向 macOS 26 的玻璃视觉进行适配。
- 把低功耗作为核心验收条件，而不是后续优化项。
- 支持登录后自动启动。

## 目标设备

- MacBook Air，Apple M5
- 16 GB 内存、512 GB 存储
- macOS 26.5.2

## 项目原则

- 优先采用 macOS 原生技术与系统视觉语言。
- 面板打开时及时刷新，关闭后降低采集频率或暂停非必要采集。
- 尽量避免持续运行外部命令、高频轮询、后台动画和不必要的系统唤醒。
- 数据默认只在本机处理；任何联网行为都需要明确用途。

## 当前状态

首版已经构建完成，应用交付物位于 `outputs/`。AirPods Pro 已完成实机快照验证，面板会显示左右耳、充电盒电量与连接/充电状态；不同放置组合仍可在日后继续做状态矩阵校准。

## 安装与运行

1. 解压 `outputs/edison.app.zip`，或直接使用同目录的 `edison.app`。
2. 将 `edison.app` 拖到“应用程序”，双击启动。
3. 如果 macOS 首次拦截自签名应用，在 Finder 中对应用点按右键，选择“打开”并确认。

应用是菜单栏应用，不会出现在 Dock。点击菜单栏中的单色“10”图标打开面板；设置页可以关闭或恢复登录后自动启动。

## 低功耗行为

- 面板关闭时暂停 CPU/GPU/温度采样，不运行周期性 Codex 子进程。
- 面板打开时 CPU/GPU/温度每秒采样，保留最近 60 个点；AirPods 默认每 30 秒读取一次。
- Codex 只在面板打开且缓存过期时按需查询，读取后退出官方 app-server；重置倒计时在本地计算。
- 睡眠时暂停任务，唤醒后重建 CPU 基线并刷新面板数据。

## 数据边界

- 温度数值依赖 M 系列机型的系统传感器；读取不到时只显示系统热状态，不伪造摄氏度。
- GPU 利用率依赖 Apple 图形驱动公开可读的 PerformanceStatistics；驱动不提供时显示“暂不可用”。
- Codex 额度通过官方 app-server 的 `account/rateLimits/read` 读取，不读取或记录 token、邮箱或原始认证文件。
