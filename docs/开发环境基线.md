# 开发环境基线

记录日期：2026-08-13

## 目标设备（已在本机核对）

- MacBook Air（Mac17,3）
- Apple M5
- CPU：10 核（4 个性能核、6 个能效核）
- GPU：8 核
- 内存：16 GB
- 存储：512 GB 规格
- macOS：26.5.2（25F84）

出于隐私与安全考虑，本项目不记录设备序列号、Hardware UUID、UDID 或账户令牌。

## 当前开发工具

- Apple Command Line Tools 已安装
- Swift 6.2.3，目标为 `arm64-apple-macosx26.0`
- 当前未安装完整的 `Xcode.app`

## 对开发流程的影响

- 可以先用 Swift Package Manager、SwiftUI/AppKit 和命令行构建方式制作并验证原型。
- 正式资源目录、应用图标、签名、公证或某些 Instruments 性能分析能力可能需要完整 Xcode。
- 在确认现有工具链确实无法完成某一步之前，不要求安装额外工具。

## 已验证的命令行编译约束

- 直接使用 `swift -e` 时，解释器可能选择 `arm64e` Swift 接口；当前编译器与该 SDK 接口的补丁构建号不完全一致，会报 SDK/compiler mismatch。
- Codex 沙箱不能写默认的 `~/.cache/clang/ModuleCache`。
- 使用 `swiftc`，显式指定 `-target arm64-apple-macosx26.0`、系统 SDK，并把 `-module-cache-path` 指向 `/private/tmp` 后可正常类型检查。
- SwiftUI 的 macOS 26 `glassEffect()` 已按上述方式验证通过，因此原型阶段不依赖完整 Xcode。
